# LintelDesk

**A private, offline-first productivity suite for Windows.**

LintelDesk brings your everyday productivity tools together in one application. Create documents, work with spreadsheets, organize tasks, and capture ideas on a canvas — without depending on a cloud-based workspace.

🌐 **Website:** https://linteldesk.com/

## Overview

LintelDesk is designed for people who want a straightforward productivity workspace with an emphasis on local file storage and offline use.

Instead of requiring an account to get started, LintelDesk is built around a simple principle: your productivity tools should work for you without unnecessary complexity.

## Features

- **Docs** — Create and manage documents.
- **Sheets** — Work with spreadsheet-style data.
- **Tasks** — Organize tasks and stay on top of your work.
- **Canvas** — Capture ideas and organize your thoughts visually.
- **Offline-first** — Designed to work without relying on a constant internet connection.
- **Local storage** — Files are stored locally on your device.
- **No account required** — Use the application without creating an account.

## System Requirements

- **Operating system:** Windows 10 or Windows 11
- **Architecture:** 64-bit Windows
